# MCP Token Lab — Monogram M

## Included
- `mcp-token-lab-logo.svg`: True vector, solid black, transparent background, cubic Bezier curves.
- `mcp-token-lab-logo-white.svg`: White reversed mark for dark mode.
- `mcp-token-lab-favicon.svg` / `mcp-token-lab-favicon-white.svg`: same geometry with tighter safe area for small rendering.
- `mcp-token-lab-{16,24,32,48,64,128,256,512,1024}.png`: transparent black PNG exports; 16–32px use optical-viewBox favicon.
- `favicon.ico`: 16–256px multi-size icon.
- `mcp-token-lab-white-1024.png`: transparent white mark.
- `mcp-token-lab-512-white-bg.png`: opaque white-background export.
- `mcp-token-lab-brand-preview.png`: light/dark board.
- `mcp-token-lab-size-qa.png`: actual-pixel comparison.

## Colors
Only `#000000` and `#FFFFFF` are specified in source SVGs. No alpha layering, gradients, or raster tracing.

## HTML usage
`<link rel="icon" type="image/svg+xml" href="/favicon.svg">`
For browser tab, deploy `mcp-token-lab-favicon.svg` as `/favicon.svg`. For fallback deploy `favicon.ico` as `/favicon.ico`.
