# 会话模拟与配置参考

[← 返回项目介绍](../README.md)

本文说明 MCP Token Lab 的计费口径、方案配置格式和 Session 接口。

## 计算与展示口径

所有长度参数与 Session 结果均使用 **K Token**（1K = 1,000 Token），模型价格是每百万 Token 单价。费用 = K Token ÷ 1,000 × 单价。

所有预设、手动费率、图表和导出费用统一使用美元（USD），单价显示为 $/M（每百万 Token）。全部模型费率直接以 USD 维护在 `model-pricing.js`。

每个方案拥有独立的参数、流程、模型和费率。默认两套流程分别在每轮查询所需 Schema，或在初始阶段预加载全部 Schema。Session 不区分工具模式，仅按流程数组执行；后续编辑互不影响。初始上下文、缓存命中、压缩触发和保留顺序都由 Session 决定。每轮流程结束后检查压缩，最后一轮触发的压缩请求也计费。

用户轮次不包括初始上下文和压缩摘要的内部 Turn。压缩请求归入触发它的用户轮次，显示压缩前后长度、删除轮次及保留轮次。摘要输出长度不等于压缩后的总上下文。

“平均每 X 轮用户消息触发一次压缩” = 实际用户消息总轮数 ÷ 实际压缩次数，包含末次压缩后的用户轮次。由 `Session.getConsumptionTokens()` 返回 `averageUserTurnsPerCompression`，未触发压缩时为 `null`，页面显示“未触发压缩”。

“每轮平均TTFT” = 每轮实际执行节点与压缩调用的累计耗时 ÷ 用户轮次，单位为秒。步骤的 `durationSeconds` 可设置非负有限数值，省略时 `action`（工具 / 上下文）默认 0.3s，`llm` 默认 1.8s；显式设为 0 表示不耗时。停用或未触发节点不计时，初始上下文的一次性加载不计入平均值，压缩调用固定按 1.8s 计入触发轮次（包含末轮）。LLM 输出不会重复计时，工具节点耗时按节点执行一次计算，不随 Token 长度或平均工具数量倍增。

「是否模拟耗时」分为全局与方案两级，省略时均默认为 `true`。在「全部变量 → 会话规模」设置 `globalSimulation.estimateDuration`：选择「是」展示「每轮平均TTFT」列，选择「否」隐藏整列，展开详情的列跨度同步调整。在「方案配置变量」或「方案全部变量」中设置 `plans[i].estimateDuration`：选择「否」仅关闭该方案的耗时模拟，对应单元格显示「—」，不隐藏表格列，也不影响其他方案；即使所有方案都关闭，全局开启时仍保留该列。全局关闭优先于方案设置，重新开启后保留各方案的独立选择。保存后生效，节点耗时配置与费用、Token 结果保留。报告返回 `averageTurnDurationSeconds` 与每轮的 `durationSeconds`；关闭模拟时均为 `null`，没有用户轮次时平均值也为 `null`。空流程且不触发压缩时，每轮耗时为 0。方案开关随 JSON 导入导出及复制保留。

输入归因直接读取每次请求的 `actionGroupTokens`，输出归入对应输出 Action 的 group。保留轮次在压缩后的请求中归入“压缩保留轮次”，历史归因不改变。“压缩摘要”是内容来源，“压缩请求费用”是请求分类，两者不可相加。

页面最多支持 8 个方案，每个方案支持 1–1,000 轮，计算在 Worker 中执行，超过 20 秒可减少方案数量、轮次或压缩阈值重试。不会为了提高性能改变 Session 的快照或引用匹配机制。图表采样保留压缩事件和峰值，明细每页 5 个用户轮次。

页面导出 v4 多方案配置，包含全部方案和对比基准；可导入 v4，并兼容 v2 / v3 旧配置。旧模式条件在导入时解析成实际步骤，导出与运行时均不再包含 `toolsMode`。v2 会话配置迁移为两套独立流程。不迁移 v1 旧计算器数据。配置仅使用美元费率，导出和导入均保留费率数值，不会被预设覆盖。编辑模型或价格后标记为自定义费率。首次打开、刷新和恢复默认方案时均选择模型列表第一项，当前为百炼 Qwen3.8 Max；Session 不内置默认费率。配置仅保留在当前页面内存中，需要留存时可导出 JSON。


## 方案管理与比较

- 点击对比卡片上的编辑按钮打开独立草稿编辑窗口，分为基本参数、执行流程、缓存与压缩、模型与费率四区。保存后校验并更新对比；取消、关闭或按 Escape 会丢弃草稿。
- 「新增方案」以默认按需流程开始，并沿用现有方案的模型费率，可切换预加载或空白流程作为起点；「复制」会完整复制选中方案，嵌套配置独立。新增与复制均在保存后加入对比。
- 默认方案也可删除，包括删除全部方案。新增、编辑、删除、切换基准、导入和恢复默认方案均可撤销最近一次操作；关闭通知会清除撤销记录。
- 对比基准默认自动使用总费用最高的方案，同价时使用列表中的首个方案；点击卡片星标可手动固定任意基准，后续修改方案时保留手动选择。删除基准后恢复自动选择；没有方案时基准为 `null`。恢复默认方案会恢复自动选择。
- 概览展示各方案实际用户轮次、模型、总费用和相对基准的差额。单方案展示计算结果；空方案显示新增入口。
- 费用来源使用堆叠条形图和动态费用列，按来源名称对应的 key 对齐，缺失来源计为零。趋势图与请求明细支持全部方案。
- 对比要求使用同一币种，不自动换汇。轮次数不同会提示比较口径；基准费用为零时差额比例显示「—」。
- 配置为 `{ version: 4, unit: "K", baselineId, baselineMode, plans }`；`baselineMode` 为 `auto` 或 `manual`，未提供时保留导入配置的基准选择。每项包含 `id`、`name`、`color`、`simulation`、`model`、`pricing`。方案 ID 和名称需唯一。
- 方案配置仅存于页面内存；可通过 JSON 保留配置，通过 CSV 导出包含真实方案名称的请求或费用来源。


## 自定义会话流程

编辑窗口的「执行流程」可分别编辑初始上下文与每轮流程：新增、复制、删除、改名、调整顺序、启用 / 停用，以及设置固定 Token 或公式。支持撤销最近一次步骤删除，切换编辑分区不会清除该记录；更换流程模板会清除。配置导出会包含完整流程。

画布交互：

- 点击节点之间（含首尾）的「＋」，选择追加上下文或调用模型，在该位置插入；初始阶段仅提供追加上下文。
- 拖动节点左侧手柄调整顺序，暖色横线标记松手后的位置；靠近屏幕上下边缘时自动滚动。鼠标和触屏均支持，Escape 可取消。
- 节点底部提供上移、下移、复制与删除。键盘聚焦手柄后可用 Alt + ↑ / ↓ 排序；首尾越界按钮禁用。
- 节点移动后，右侧继续编辑原选中的节点；复制或插入后选中新节点。长流程的桌面属性面板保持可见。
- 删除后在画布上方点击「撤销删除」恢复最近删除的节点，可跨初始／每轮阶段恢复；切换方案草稿时清除该记录。空流程也可以从「添加第一个节点」重新开始。

直接调用 Session 时使用 `config.flow.initial` 和 `config.flow.turn`；页面 v4 JSON 中位于 `plans[i].simulation.flow`（旧 v2 为 `simulation.flow`）。不提供流程或省略某个阶段时使用该阶段默认流程，显式传入 `[]` 表示空流程。步骤仅支持 `type`、`text`、`token`、`enabled`、`trigger`、`durationSeconds`，未知字段会被拒绝。之前不含 `flow` 的 v2 配置仍可导入。

```js
import Session from "./src/session.js";

const session = new Session({
  turnTotalCount: 10,
  model: { inputCachedPrice: 1.5, inputNotCachedPrice: 12, outputPrice: 36 },
  flow: {
    initial: [
      { type: "action", text: "系统提示", token: "initialContext.agentPromptToken" },
      { type: "action", text: "业务背景", token: 2 },
      {
        type: "action",
        text: "工具定义",
        token: "toolsTotalCount * toolSchemaToken",
      },
    ],
    turn: [
      { type: "action", text: "用户提问", token: "userMessageToken" },
      { type: "llm", text: "检索计划", token: 0.2 },
      { type: "action", text: "检索结果", token: "Math.ceil(toolResultToken * turnAvgToolsCount)" },
      { type: "llm", text: "最终回复", token: "agentResult" },
    ],
  },
});
session.reset();
const totals = session.getConsumptionTokens();
```

| 步骤字段 | 含义 |
|---|---|
| `type` | `action` 追加上下文；`llm` 请求当前有效上下文，并将输出追加到上下文。初始阶段只接受 `action`。 |
| `text` | 非空名称，同时作为费用归因来源；相同名称合并统计。 |
| `token` | 非负有限数字（K Token）或 JS 数值表达式字符串。兼容旧版非空参数名数组（依次相乘）。`llm` 的 Token 表示输出长度，输入长度自动取当前上下文。 |
| `enabled` | 可选布尔值，`false` 跳过该步骤，默认启用。 |
| `durationSeconds` | 可选非负有限数值，单位为秒。省略时 `action` 默认 0.3s，`llm` 默认 1.8s；支持显式设置为 0。 |
| `trigger` | 仅用于 `flow.turn`。省略时每轮执行；`{ type: "probability", value: 30 }` 表示每轮 30% 概率；`{ type: "interval", value: 3 }` 表示每 3 轮用户消息执行一次。 |

### 节点触发方式

每轮流程中的追加上下文与模型调用节点都可独立设置触发方式。编辑器的「步骤属性 → 触发方式」提供每轮、按百分比和每 N 轮消息三种选择。编辑器和首页的流程预览展示首轮结果，未触发节点显示 0 K，并从首轮有效步骤与模型调用数中排除。

```js
const flow = {
  initial: [],
  turn: [
    { type: "action", text: "用户提问", token: "userMessageToken" },
    { type: "llm", text: "偶尔检索", token: 0.2,
      trigger: { type: "probability", value: 30 } },
    { type: "action", text: "定期补充资料", token: 2,
      trigger: { type: "interval", value: 3 } },
    { type: "llm", text: "最终回复", token: "agentResult" },
  ],
};
```

- 百分比为 **0–100** 的有限数值，可填小数；0% 从不触发，100% 等同每轮执行。每个节点、每个用户轮次使用固定种子的伪随机抽样，实际触发比例可能偏离设定百分比。它是一次可复现的模拟轨迹，费用不是多次随机模拟的期望值。
- 抽样取决于用户轮次索引和节点在 `flow.turn` 中的位置。相同流程在预览、Worker、`reset()`、JSON 导入后使用相同触发序列；修改费率或增加总轮次不改变既有轮次的抽样。移动或插入节点改变位置后，抽样序列也可能改变。
- N 必须是正安全整数；在第 N、2N、3N…轮触发，从第 N 轮开始。计数基于 `startNewTurn()` 创建的用户消息轮次；压缩请求不占用轮次，也不重置计数。N 大于会话轮数时不会执行。
- 未触发时完整跳过节点：不计算其 Token 公式、不追加上下文、不发起模型请求、不增加 `llmIndex`，不会产生该次节点费用。先前已触发并保留在上下文中的内容仍可产生后续输入费用。
- 触发规则**仅作用于当前节点**。模型调用未触发时，后续上下文节点仍按自己的规则执行，不自动联动。停用优先于触发规则；初始上下文不支持 `trigger`。
- 触发配置参与导入校验，并随复制、保存和 JSON 导出保留。旧配置省略 `trigger` 时行为不变。

可引用变量见 `session-flow.js` 的 `tokenParameters`：现有内容长度、Skills / Tools 总数、每轮平均数量以及会话总轮次 `turnTotalCount`。方案参数取当前配置值；长度单位是 K Token，比例使用 0–1。点击「插入变量」打开可搜索列表，查看变量名称、中文说明和当前预览值；选中后插入到原光标位置，或替换原选区。取消或按 Escape 只关闭变量弹框，不丢弃方案草稿。

另外提供两个运行变量：

| 变量 | 规则 |
| --- | --- |
| `turnIndex` | 用户轮次索引，从 0 开始；首轮为 0，压缩不占用轮次索引。 |
| `llmIndex` | 当前步骤前已执行的模型调用数；本轮第一次调用取 0，第二次取 1。普通内容步骤取已完成调用数，每轮重置，停用或未触发的调用不计数。 |

初始阶段两者均为 0。每轮流程可选择预览消息轮次，对应 `turnIndex = 消息轮次 - 1`，编辑器按实际触发顺序计算 `llmIndex`；预览不会改变会话轮数。保存校验默认使用首轮索引，间隔节点使用首次触发轮次，概率节点在会话前 1,000 轮内寻找首次触发轮次（未找到或停用时用首轮检查）；执行时仅对实际触发节点逐步求值；若后续轮次得到无效结果，计算会停止并报告具体步骤、`turnIndex` 和 `llmIndex`。

长度设置提供两种方式：

- **固定 Token**：直接输入非负长度。
- **公式**：输入单个 JavaScript 数值表达式，无需 `return`；输入时预览结果，保存前验证。切换方式会保留各自输入。

```js
// 单个工具返回长度 × 每轮工具数
"toolResultToken * turnAvgToolsCount"
// 向上取整（取整单位也是 K Token）
"Math.ceil(toolResultToken * turnAvgToolsCount)"
// 限制最大长度为 10K Token
"Math.min(toolResultToken * turnAvgToolsCount, 10)"
// 按数量分支
"turnAvgToolsCount > 0 ? toolResultToken * turnAvgToolsCount : 0"
// 输出随用户轮次增长
"agentResult * (turnIndex + 1)"
// 区分轮内模型调用
"llmIndex === 0 ? readSkillPlanToken : agentResult"
```

支持算术 `+ - * / % **`、括号、比较 `> >= < <= == != === !==`、逻辑 `! && || ??` 和三元表达式 `条件 ? 值1 : 值2`。函数包括 `Math.min/max/ceil/floor/round/trunc/abs/sqrt/pow/log/log2/log10/exp`，常量包括 `Math.PI` 和 `Math.E`。公式结果必须是非负有限数字；未知变量、无效语法、负值或非有限结果会提示错误并阻止保存。

公式由 Acorn 解析后，仅解释上述数值语法；不使用 `eval` 或 `Function`，不允许赋值、函数定义、全局对象、随机数、网络或任意属性访问。每条公式最多 2,000 字符、256 个求值节点、32 层嵌套。流程仍为可导入导出及传入 Worker 的纯 JSON 数据，旧参数名字符串及参数乘积数组继续兼容。

轮次通过 `kind`（`initial` / `user` / `compression`）区分，不依赖步骤名称。每次 `startNewTurn()` 算一轮，即使没有用户消息步骤或模型调用，也会在轮末检查压缩。Token 阈值包含最后一次模型调用之后追加的内容。初始上下文的引用在本次运行中保持稳定，`reset()` 会按最新参数和流程重新创建初始上下文。

| 方案 | 普通请求 / 压缩请求 | 最终上下文 K | 费用 USD |
|---|---:|---:|---:|

### 全局参数与方案覆盖

首页保留常用全局配置，点击「全部变量」可编辑全部内置参数，以及新增、修改、删除自定义数值变量。方案编辑页和流程公式旁也提供变量入口；弹窗中的修改在保存后生效，取消或按 Escape 会丢弃本次弹窗修改。

`globalSimulation` 保存全部内置数值参数（包括内容长度、平均调用数量及压缩配置），以及布尔变量 `estimateDuration`。全局 `estimateDuration` 控制耗时列显隐，方案级 `estimateDuration` 仅控制对应方案的耗时值。`useGlobal` 按字段记录是否继承；新方案默认全部继承。方案内点击「继承全局 / 自定义」可切换来源，直接修改数值会自动切为自定义。计算、校验和草稿预览均使用实际生效的值。

命中率在配置中为 0–1，页面显示为 0–100%。压缩方式为 `TURN` 或 `TOKEN`，页面仅显示当前方式的阈值（轮 / K Token），切换方式时保留两种阈值。方式和阈值可以分别覆盖，轮次阈值仍必须大于该方案的保留轮次。

旧配置新增全局控制时补齐其展示初值，但没有继承标记的方案字段继续使用原独立值，避免导入后改变模拟结果。

自定义变量保存在 `globalSimulation.variables` 或方案的 `simulation.variables` 中，例如：

```json
{ "retrievalToken": { "label": "检索内容长度", "value": 2.5 } }
```

公式可直接使用 `retrievalToken * 2`，也可以从「插入变量」列表选择。变量名以英文字母或下划线开头，只能包含字母、数字、下划线，最长 64 字符；不得与内置参数、运行变量或保留名称冲突。值必须为非负有限数，每个生效方案最多 100 个自定义变量。

全局自定义变量默认被所有方案继承，`useGlobal["variables.retrievalToken"] = false` 表示使用方案独立值；也可以只在某个方案内新增变量。删除前会检查公式引用并指出相关方案和节点；删除全局变量时，已有独立值的方案保留该变量。内置参数不可删除，`turnIndex` / `llmIndex` 仍由模拟引擎生成。
