# Feature screenshots

These screenshots are crops of the English-language full-page screenshot supplied by the project owner. They reflect a particular captured UI state; they are not new live-browser captures of interactive dialogs.

The WebP assets are optimized for GitHub README display. The original PNG crops and complete source screenshot remain in the local README kit; they are not committed to this branch.
