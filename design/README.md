# Token Lab · 工作台设计提案

可交互的高保真设计稿，入口为项目根目录的 `design.html`。主页面与流程编辑器使用现有 Vue、ECharts 与会话计算引擎。

## 打开预览

启动项目开发服务后，打开 `/design.html`。当前本地地址：

http://localhost:5174/design.html

独立构建：

```sh
npx vite build --config design/vite.config.js
```

构建结果位于 `output/design-preview/`，入口为 `design.html`。此命令不会上传 CDN。

## 设计取舍

- 浅灰白底、石墨色文字、低饱和绿色。用字号、间距和细分隔线组织层级；不使用背景字符、发光边框或循环动画。
- 顶部实验条件压缩成一行，更多参数按需展开。
- 将大面积方案卡片改成横向对比表，统一对齐费用、基准差异、命中率、峰值请求输入与请求次数；支持最多八个方案。
- 将节省结论置于对比表下方；费用组成、主要来源与累计趋势并排呈现。
- 请求明细独立为视图，支持普通 / 压缩请求筛选、分页与 CSV 导出。
- 方案编辑使用独立工作区：分区导航、步骤列表、属性面板。选中步骤后直接修改，不需要展开多层卡片。
- 底部展示草稿的实时成本及相对编辑前的变化；保存才更新正式方案，取消可放弃草稿。
- 窄屏下分析面板与编辑区依次堆叠，降低横向拥挤。

## 可体验范围

全局参数调整、方案新增 / 复制 / 删除、基准切换、撤销、配置导入导出；流程增删与排序、步骤启停、固定长度与公式、变量插入、模型预设、费用归因与请求记录。

金额与 Token 数值由现有模拟引擎计算，不是静态演示数字。价格为项目自带快照。配置仅保留在本次页面会话中，刷新前需导出。

## 验证记录

- 设计入口独立构建通过。
- Chrome「用户1」验证桌面页面与 390px 窄屏，无页面横向溢出。
- 将 Agent Prompt 公式由 `initialContext.agentPromptToken` 改为两倍：步骤预览由 4K 变为 8K，会话成本由 $77.79 变为 $82.00；保存更新对比，撤销恢复原结果。
- 未知公式变量会显示错误并阻止保存；取消可返回原方案。
- 压缩请求筛选得到 12 次请求，分页第二页显示剩余 4 条。
- 原项目测试结果为 51 / 52：既有测试要求拒绝 `Math.random()`，现有引擎允许该函数。本次未改动引擎或其测试。
