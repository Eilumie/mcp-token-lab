## 为什么做 MCP Token Lab？

一次 Agent 任务，通常包含多次模型调用。系统提示、工具定义、检索结果和历史消息会反复进入上下文；缓存命中率与压缩策略，也会改变最终账单。

MCP Token Lab 是一个**可自定义流程的 Agent 会话成本模拟器**。你可以把会话拆成“追加内容”和“调用模型”两类步骤，为每一步设置预计 Token 用量，再比较不同方案的完整会话费用。

它帮助你回答：

- 工具定义放在初始上下文，还是在需要时查询，费用会差多少？
- 减少一次模型调用，能省下多少输入与输出成本？
- 缓存命中率变化，会怎样影响长会话的累计费用？
- 多久压缩一次上下文、保留几轮历史，更适合当前流程？
- 同一套流程，更换模型费率后的成本差异有多大？

**所有模拟在浏览器本地完成，无需 API Key，也不会调用真实模型。** 输入的是预计 Token 长度，结果用于方案估算；模型质量、实际延迟和真实缓存命中情况需要另行验证。

界面采用简洁数字风与轻量白色卡片。极淡的 Glyph Matrix 在鼠标附近渐变清晰并轻微放大；系统减少动态效果设置下保留静态背景。

## 支持平台与 Agent 开发约束

本项目仅支持桌面端浏览器，**不支持移动端**，请在电脑上使用。

Agent 修改界面时，应以桌面端体验为准，**不要进行移动端适配**，包括新增移动端布局、针对手机或平板的响应式断点及触控专用交互。除非用户明确要求，否则不要主动新增、补全或优化移动端适配。

## 核心功能

| 功能 | 你可以做什么 |
| --- | --- |
| **多方案独立对比** | 同时比较最多 8 个方案，各自配置流程、参数和模型费率；支持新增、复制、删除，并可撤销最近一次配置变更。 |
| **方案对比表** | 在首页查看总费用、相对基准、初始上下文、模型请求与上下文压缩；展开方案可查看费用卡片和执行流程。 |
| **全局模型与会话规模** | 页面顶部统一选择模型并设置用户轮次、Skills / Tools 总数、Prefix 命中率、压缩阈值类型与阈值。可在「全部变量」中手动设置全局模型名称和费率；各方案默认继承，也可独立设置或恢复继承。导入旧配置时保留原方案数值、模型和费率。 |
| **两阶段流程编辑** | 分别设计初始上下文和每轮执行流程，自由增删、复制、排序、改名或停用步骤，并实时预览费用。 |
| **参数化 Token 用量** | 为步骤选择固定 Token 或 JS 公式，支持变量、条件表达式与 Math 函数，实时预览结果。 |
| **缓存与压缩模拟** | 设置前缀期望命中率；按轮次或 Token 阈值触发压缩，并配置保留轮次与摘要长度。 |
| **费用归因与请求追踪** | 查看每个来源的输入、输出与费用；通过趋势图和请求明细追踪会话变化。 |
| **配置与结果导出** | 用 JSON 保存或分享完整方案，用 CSV 导出请求记录与费用来源。 |

页面提供两套开箱即用的流程：**渐进式Tools Schema** 和 **MCP默认全量tools/list**。两者都是可编辑的普通方案，计算引擎统一按步骤执行，你也可以建立完全不同的流程。

## 快速开始

需要 **Node.js 20.19+ 或 22.12+**。

获取项目源码后，在项目目录运行：

```sh
pnpm install
pnpm dev
```

打开终端显示的本地地址，即可开始对比。

1. **选一个方案**：先使用默认流程，或复制一份作为新的实验方案。
2. **编辑独立草稿**：点击对比表中的编辑按钮，在基本参数、执行流程、缓存与压缩、模型与费率四个分区中调整；保存后更新对比，取消不影响原方案。
3. **选择对比基准**：默认自动使用费用最高的方案，也可通过表格中的「更多 → 设为基准」手动固定基准，查看总费用、费用差额、来源分布和会话趋势。
4. **保存实验**：导出 JSON 留存配置，或导出 CSV 分析结果。

配置保存在当前页面内存中，刷新页面会恢复默认值；需要保留的方案请先导出 JSON。

### 让 Agent 生成对比配置

仓库提供 [mcp-token-lab skill](skills/mcp-token-lab/SKILL.md)，指导 Agent 将流程描述转换为可导入的 v4 多方案 JSON，包含字段约束、全局继承规则、公式、触发方式及预估耗时。`skills/mcp-token-lab/` 是本项目开源源码的一部分，说明文档、示例和校验脚本随仓库一起发布和维护。使用者可按需将该文件夹安装到自己的 Agent skills 目录，再这样使用：

```text
使用 $mcp-token-lab，比较 60 个工具的按需 Schema 与全量预加载：
20 轮用户消息，每轮平均调用 1.5 个工具，每个工具返回 3K Token。
使用相同模型和费率，生成可导入页面的 JSON，并列明其余假设。
```

也可在「模板 → 导入自定义模板」导入 [完整双方案示例](skills/mcp-token-lab/assets/comparison.example.json)，预览后点击「使用模板」；文件包含模板名称、模板描述和 v4 多方案配置。示例费率为演示假设，请按实际模型调整。生成的 JSON 可在项目目录用页面真实的导入逻辑校验，并完整模拟：

```sh
node skills/mcp-token-lab/scripts/validate-config.mjs --repo . path/to/comparison.json --simulate
```

## 自定义流程

一次会话由两个阶段组成：

```text
initial：建立初始上下文
    ↓
turn：追加用户消息 → 模型生成计划 → 追加工具结果 → 模型生成回复
    ↓
检查压缩阈值 → 必要时调用模型生成摘要
    ↓
进入下一轮，直到完成设定轮次
```

每个步骤只需描述名称、类型和 Token 长度。下面是一段可在项目根目录通过 Node.js ES Module 运行的示例：

```js
import Session from "./src/session.js";

const session = new Session({
  turnTotalCount: 10,
  expectedPrefixCacheHitRate: 0.9,
  // 示例单价，单位：美元 / 百万 Token；请替换为所用模型的费率。
  model: {
    inputCachedPrice: 1.5,
    inputNotCachedPrice: 12,
    outputPrice: 36,
  },
  flow: {
    initial: [
      { type: "action", text: "系统提示", token: 2 },
      { type: "action", text: "业务背景", token: 1 },
    ],
    turn: [
      { type: "action", text: "用户提问", token: 0.1 },
      { type: "llm", text: "检索计划", token: 0.2 },
      { type: "action", text: "检索结果", token: 3 },
      { type: "llm", text: "最终回复", token: 1 },
    ],
  },
});

session.reset();
const totals = session.getConsumptionTokens();
console.log("预计会话费用：", totals.totalPrice);
```

- `action`：向上下文追加内容，例如系统提示、用户消息或工具返回。
- `llm`：以当前有效上下文作为输入，生成指定长度的输出，并追加到上下文。
- `token`：以 **K Token** 为单位；`1` 表示 1,000 Token。支持固定数字或公式字符串，例如 `"Math.ceil(toolResultToken * turnAvgToolsCount)"`。点击「插入变量」可选择变量，并通过「可用参数值」查看当前取值。公式还可使用从 0 开始的用户轮次 `turnIndex` 和本轮模型调用索引 `llmIndex`，例如 `"agentResult * (turnIndex + 1)"`。
- `enabled: false`：跳过步骤，方便比较删减某一步后的效果。

初始阶段支持 `action`，每轮阶段支持 `action` 和 `llm`。流程是纯 JSON 数据，可在页面、配置文件和 Worker 之间传递。

更多参数、缓存匹配规则和压缩细节，见 [会话模拟与配置参考](docs/simulation.md)。

## 如何理解结果

```text
请求费用 = 命中输入 K ÷ 1,000 × 命中输入单价
         + 未命中输入 K ÷ 1,000 × 未命中输入单价
         + 模型输出 K ÷ 1,000 × 输出单价

会话总费用 = 所有普通请求费用 + 所有压缩请求费用
```

- **上下文会累积**：后续调用会重新读取当前有效上下文，一段内容可能产生多次输入费用。
- **缓存按前缀匹配**：引擎按动作引用匹配输入前缀，再应用配置的期望命中率；首次请求的初始上下文也按该期望值估算。
- **压缩本身也收费**：每轮流程结束后检查阈值，压缩请求的输入和摘要输出均计入总费用，包括最后一轮触发的压缩。
- **对比口径要一致**：所有方案统一以美元（$）比较；轮次数不同，比较的是各自完整会话的总费用。
- **模型费率是快照**：内置费率不会联网更新。全局配置和独立方案均可手动调整单价。模拟器不会对真实文本进行分词计数。
- **统一美元费率**：全部模型费率直接以 USD 维护，数值按美元计价。新增 OpenAI GPT、Anthropic Claude、Google Gemini 官方美元报价（2026-10-21 核对）；分档、优惠截止时间和未计入的缓存附加费用会在模型与费率面板说明。

## 本地验证与构建

```sh
# 运行计算、流程、配置迁移与多方案测试
pnpm test

# 构建静态页面（只生成 dist，不上传任何服务）
pnpm build

# 预览构建产物
pnpm preview
```

`pnpm build` 只生成可部署的静态文件到 `dist/`，不会上传 CDN，也不会访问公司内部服务。部署请使用你自己的静态托管平台或 CI 流程。

GitHub Actions 会在每次提交和 Pull Request 中自动运行 `pnpm test` 与 `pnpm build`。

## 项目结构

```text
src/
├── main.js                # 唯一页面入口
├── App.vue                # 页面状态、方案管理与草稿编辑
├── session.js             # 通用流程执行、缓存、压缩与计费
├── session-defaults.js    # 默认会话参数
├── session-flow.js        # 流程模板、Token 参数与步骤校验
├── token-formula.js       # JS 数值表达式解析与受限求值
├── session-report.js      # 请求记录、费用归因与会话汇总
├── session.worker.js      # 在 Worker 中执行模拟
├── comparison.js          # 独立方案、对比基准与配置校验
├── config.js              # 参数表单定义与配置读取
├── legacy-config.js       # 旧配置转换为独立流程
├── model-pricing.js       # 内置模型费率快照
├── components/
│   ├── Home.vue           # 首页全局配置、方案对比表与操作菜单
│   ├── PlanFlowPreview.vue # 展开方案的执行流程预览
│   └── …                  # 当前页面使用的共享组件
├── styles/                # 应用、首页与流程预览样式
├── charts.js              # 费用来源与会话趋势图
└── export.js              # CSV 导出
```

配置采用 v4 格式，导入时兼容 v2 / v3；旧模式条件会被转换成实际流程步骤。完整格式见 [配置参考](docs/simulation.md)。
